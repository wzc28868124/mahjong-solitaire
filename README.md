# 麻将接龙在线试玩

静态网页版本，使用 GitHub Pages 托管。无需安装游戏或运行本地服务器，朋友打开部署网址即可游玩。

## 玩法

按教学点击相同、未被遮挡且至少一侧空闲的麻将牌；提供提示、洗牌、撤销、关卡与本地存档。首次音效播放可能需要先点击页面。

## 版本和边界

此项目是固定于 2026 年 10 月 12 日的浏览器游戏包独立适配副本，不是官方服务。保留原版英文界面与美术，移除广告、统计及父页面通信；每日挑战使用备用题库，不代表线上每日题目。手机建议横屏。

进度只保存在当前浏览器、当前域名下，不上传云端。网站与电脑上的本地版本存档不同，清除网站数据会删除进度。

## 部署

仓库 Settings → Pages，发布来源为 main 分支、根目录。`.nojekyll` 保证直接发布静态文件。资源路径支持项目子目录部署，不需要 npm、Node.js、后端、数据库或 GitHub Actions 自定义工作流。

运行文件仅包括 HTML、CSS、JS、图集、场景、字体与音效；不包含 Windows 便携版运行时、日志或浏览器存档。代码与资源随公开仓库对外可见，本仓库未替原游戏素材授予额外许可。
